# 02 · 数据契约

本文件冻结 **widget 与数据源之间的形状**。改结构必须同时改这里并升 `schemaVersion`；
新增可选字段不升版本（消费方忽略未知字段、缺失内容字段按空串、缺失状态字段按 null）。

## 1. feed（v0 的唯一数据源）

URL 默认：`https://eastmg.github.io/gacha-calendar-app/data/latest.json`
（`gacha-calendar-app` 的 GitHub Actions 每 6 小时重抓一次并重新部署，28 款全量）

```jsonc
{
  "schemaVersion": 1,
  "refreshedAt": 1792554834054,          // 抓取完成时间（Unix 毫秒）
  "parserVersions": { "genshin": 1, "nte": 3, "r1999": 3 },  // 诊断用
  "games": {
    "genshin": {
      "name": "原神",
      "banner": "「虚星临渡」107期角色活动祈愿",
      "roles": "「虚渊暗星·丝柯克(冰)」、「明绚千韵·爱可菲(冰)」",
      "bannerDates": "10-13 18:00 ~ 11-03 14:59",   // 展示用短文本（MM-dd HH:mm ~ MM-dd HH:mm）
      "bannerDatesRaw": "10-13 18:00 ~ 11-03 14:59", // 源站原文（悬停用）
      "bannerHover": "…多行明细（可含多个池）",
      "event": "「往冥府的安魂歌」",
      "eventDates": "09-23 10:00 ~ 11-03 14:59",
      "eventDatesRaw": "…",
      "eventHover": "…",
      "gachaFail": null,                    // null | {"kind":"nomatch"} | {"kind":"down","reason":"HTTP 403"}
      "eventFail": null,
      "gachaStale": false,                  // 该列沿用了上一次成功值
      "eventStale": false,
      "okAt": 1792554834054                 // 最近一次两侧都拿到新数据的时间
    }
  },
  "meta": {
    "generatedAt": "2026-10-21T03:53:54.055Z",
    "okCount": 23, "failCount": 3, "total": 28,
    "generator": "tools/refresh-data.mjs"
  }
}
```

要点：

- `games` 是**对象**（key = 稳定 id），不是数组；**28 款全在**，包括出厂默认隐藏的 5 款。
- 内容字段恒在（缺失为空串）；状态字段恒在。
- `*Dates` 是**源站墙钟的短文本**，不带年份、不带时区。倒计时解析规则见 `RowBuilder.ParseRange`：
  解析 `MM-dd HH:mm` → 按本地墙钟比较；跨年时取"离 now 最近的年份候选"。
- `bannerHover` / `eventHover` 是多行明细，桌面端作 tooltip，触摸端可点开（本仓库 v0 作 tooltip）。
- `meta` 只用于诊断/状态文案，不参与行渲染。

## 2. catalog（本地元信息，feed 里没有）

`data/catalog.json`，由 `tools/gen-catalog.mjs` 从 `gacha-calendar-core` 的
`engine.listGames()` / SOURCES 表生成；**不要手改**，改完跑 `node tools/gen-catalog.mjs --check`。

```jsonc
{
  "schemaVersion": 1,
  "generatedAt": 1792554834054,
  "coreVersion": "0.12.5",
  "games": [
    {
      "id": "genshin",
      "name": "原神",
      "icon": "https://…",     // 外链图标；拿不到时为空串，UI 退化为首字色块
      "order": 0,              // core 默认顺序
      "defaultHidden": false,  // 出厂隐藏（5 款）
      "tz": 480                // 服务器时区偏移（分钟），v0 仅记录，倒计时仍按墙钟比较
    }
  ]
}
```

## 3. 可见性与排序（UI 侧计算）

```
removed 含 id                        → 不显示
hidden 含 id                         → 不显示
defaultHidden 且 shown 不含 id        → 不显示
否则                                 → 显示
```

显示顺序：`settings.order` 里出现的按该顺序排前面，其余按 `catalog.order`。

## 4. 设置（WidBar 的 `SettingsJson`，本仓库自定义 schema）

```jsonc
{
  "previewItems": 2,          // 1..3，任务栏预览条显示几条
  "autoRefresh": true,
  "refreshMinutes": 360,      // 15..720
  "feedUrl": "https://eastmg.github.io/gacha-calendar-app/data/latest.json",
  "showGacha": true,          // 面板列开关
  "showEvent": true,
  "hidden": [], "shown": [], "removed": [], "order": []
}
```

`WidgetSettings.Normalize()` 负责 clamp、去重、剔除 catalog 里不存在的 id、feedUrl 为空回默认值。
**schema 是本仓库私有的**：WidBar 只当字符串存，不解释内容。

## 5. 兼容性约定

- 消费方对未知字段忽略；缺内容字段按空串；缺状态字段按 null。
- `schemaVersion` 不兼容变更才 +1；本项目 v0 固定为 1。
- `parserVersions` / `coreVersion` 只用于诊断（设置页的"数据自检"会展示）。
