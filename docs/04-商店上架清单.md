# 04 · 微软商店上架清单

目标：**上架微软商店**，并让 Widget 出现在 WidBar 应用内的组件目录里。

## 1. 包形态

- **MSIX**，单一 x64（可选 arm64），不建议打包 x86。
- 通过 `windows.appExtension`（Name = `com.widbar.widget`）向 WidBar 暴露自己。
- 能力：`runFullTrust`（必须）+ `internetClient`（拉 feed 与图标）。
- 不在 MSIX 里打包 Node / WebView2 / JS 引擎（v0 的包体目标：**< 60MB**）。
- `.msixupload` **只能在 CI / Visual Studio MSBuild 里出**：本机 `dotnet` CLI 会在
  `WinAppSdkCreateAppStoreContainer` 任务上因 `System.Security.Permissions` 依赖崩溃（详见 `docs/05`）。
  GitHub Actions 已配好（`.github/workflows/build.yml`），push 到 main 后在 Actions 的 `msix` artifact 里取。

## 2. 身份

| 项 | 值 |
|---|---|
| Publisher | 与 Partner Center 账号一致的证书主题（`CN=…`），**不能随手编** |
| PublisherDisplayName | `EastMG` |
| Package/Identity/Name | 建议 `EastMG.GachaCalendar`（全局唯一） |
| PackageFamilyName | 由上面两项决定，安装后可用 `Get-AppxPackage` 查 |
| DisplayName | `二游日历 for WidBar`（或 `Gacha Calendar for WidBar`） |
| 版本 | `0.1.x.0`，与 csproj `<Version>` 同源 |

## 3. 隐私

- **不收集任何用户数据、无遥测、无账号**。唯一出站请求是 `feedUrl`（默认 GitHub Pages 静态 JSON）与图标 URL。
- 商店要求可访问的隐私政策 URL：用仓库内的 `PRIVACY.md` + GitHub Pages（或 gist）发布。
- 文案要点：不采集、不共享、不用于广告与训练；日历数据在本地内存/缓存文件中，不上传。

## 4. 素材

| 素材 | 要求 |
|---|---|
| 应用图标 | 44 / 150 / 300 / 620（PNG，透明底或品牌底），另有 44×44 任务栏小图标 |
| 商店截图 | 至少 1 张，建议 1920×1080 或 1366×768；需包含任务栏预览 + 展开面板 |
| 短描述 | ≤ 200 字，写清"28 款二游卡池/活动倒计时，常驻 Win11 任务栏" |
| 详细描述 | 功能列表 + 数据来源说明 + 免责声明 |
| 分类 | 工具 → 个性化/系统工具（与 WidBar 同分类：Utilities & tools） |

## 5. WidBar 组件目录

- 上架后拿 `storeProductId`，向 [`andelby/widbar`](https://github.com/andelby/widbar) 提 PR 往 `catalog.json` 加条目：
  `id` / `pluginId` / `name` / `summary` / `publisher` / `category` / `storeProductId` / `iconUrl`（+ 可选多语言文案）。
- 图标 URL 必须公网可访问（建议放本仓库 GitHub Pages）。
- WidBar 作者会审核后合入；合入后出现在应用内 Showcase 页。

## 6. 审核风险与规避

| 风险 | 规避 |
|---|---|
| 抓第三方游戏排期内容被判定"未授权内容" | 只展示事实性排期（名称/时间），不含立绘/logo/官方 UI 素材；商店描述里注明"非官方信息聚合，权利人可要求下架" |
| 图标外链是游戏官方/商店资源 | 图标仅作标识用途；提供"图标加载失败退化首字色块"路径；必要时换成中性色块图标 |
| 网络用途申报 | 描述里写清只访问静态数据源与图标 URL，不访问游戏账号/API |
| 包体过大 | v0 不含 JS 引擎；裁剪 PDB、开启 trimming（注意 WinUI 的 trimming 限制） |
| 全信任应用审核 | WidBar 的 widget 必须 `runFullTrust`（宿主同款），说明用途：读取任务栏状态/绘制 widget |
