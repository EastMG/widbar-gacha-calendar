隐私政策 · 二游日历 for WidBar

生效日期：2026-10-21 · 适用版本：0.1.x
一句话：不收集任何数据。 不需要账号、不登录、不做统计、无遥测、无广告 SDK，也不会把使用行为发送给作者或第三方。

这个应用是什么

「二游日历」是 Windows 11 任务栏小组件 WidBar 的一个第三方组件， 用于在任务栏上展示二次元手游的卡池与活动排期。

网络请求

应用只发起两类出站请求，都在你的设备上直接完成，不经过作者的服务器：

  • 排期数据：请求一个公开的静态 JSON 快照 （默认 https://eastmg.github.io/gacha-calendar-app/data/latest.json）。 这是普通 HTTPS GET，只接受数据，不上传任何内容。
  • 游戏图标：请求公开 Wiki（萌娘百科）的图片地址，仅用于行首图标。

请求中可能带标准的 User-Agent（应用名 + 版本），用于让数据源区分客户端； 不包含设备标识、账号或位置信息。

本地存储

应用会在你的设备上保存：

  • 你的设置（显示哪些游戏、排序、预览条数、刷新间隔、数据源地址）；
  • 最近一次成功抓取的排期缓存，用于断网时显示上次内容；
  • 诊断日志（本地文本文件，仅用于排查问题）。

这些数据都在本机，不会上传；卸载应用时由 Windows 一并删除。

第三方内容

排期与图标来自各游戏官方公告与公开社区 Wiki，版权归原权利方。本应用只做信息聚合展示， 与各游戏厂商无隶属关系；权利人可要求下架相关内容。

儿童隐私

应用不收集任何个人信息，因此也不存在面向儿童的定向数据收集。

变更

若本政策变更，会更新本页面并修改生效日期；重大变更会在应用更新说明中注明。

联系方式
