## C. WidBar 里能跑起来（需要人眼/手动拖拽）

前置：WidBar 已安装、开发者模式已开、Widget 已注册。

1. 打开 WidBar → Layout 页，组件目录里应出现「二游日历」
2. 拖到任务栏空位 → 预览条出现 1–3 个两行 chip（游戏+倒计时+截止日 / ◆卡池或⚑活动+内容标题）
3. 点预览 → 展开面板：28 款可见条目、六列、顶部"联网数据 · 成功 N/M"、底部"刷新：时间"
4. 面板右上「刷新」→ 状态变为刷新中，随后时间更新（数据源 6h 一轮，短时间多次刷新可能 304）
5. 齿轮 → 设置页：改预览条数/隐藏条目/排序/刷新间隔/数据源，保存后任务栏实时变化
6. 设置页「检查数据」→ 输出"✓ 数据可用 + 源站抓取时间 + 报错条目数"
7. 深浅色主题切换：预览/面板/设置页文字与背景跟随，无白块

**本机实测现状（2026-10-21，已通过）**：签名安装后 C 段 1–7 全部通过，并有实拍截图为证
（`docs/images/preview.png` / `flyout.png` / `settings.png`）：

- SDK 日志：`Pipe connected` → `Plugin initialized` → `Instance ready` → `content=252x47dip` → `Flyout prewarmed`；
- UIA 读到的预览文本：`女神异闻录：夜幕… / 7时`、`鸣潮 / 13时`、`物华弥新 / 13时`；
- 面板顶部：`联网数据 · 成功 22/23`，28 款里默认显示 23 款，行内显示真实 UP 角色与倒计时；
- 设置页：预览条数、两列开关、自动刷新、刷新间隔、数据源地址、检查数据、条目勾选/排序、保存/取消均正常。

⚠️ 注意：早期用 `-Register` 松散注册的未签名包会因 Low IL 连不上宿主管道（`Access denied`），
**必须用 D 段的签名安装**。
