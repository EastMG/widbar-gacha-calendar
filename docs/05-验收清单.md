## C. WidBar 里能跑起来（需要人眼/手动拖拽）

前置：WidBar 已安装、开发者模式已开、Widget 已注册。

1. 打开 WidBar → Layout 页，组件目录里应出现「二游日历」
2. 拖到任务栏空位 → 预览条出现 1–3 个 chip（游戏简称 + 天数/小时/分钟）
3. 点预览 → 展开面板：28 款可见条目、六列、顶部"联网数据 · 成功 N/M"、底部"刷新：时间"
4. 面板右上「刷新」→ 状态变为刷新中，随后时间更新（数据源 6h 一轮，短时间多次刷新可能 304）
5. 齿轮 → 设置页：改预览条数/隐藏条目/排序/刷新间隔/数据源，保存后任务栏实时变化
6. 设置页「检查数据」→ 输出"✓ 数据可用 + 源站抓取时间 + 报错条目数"
7. 深浅色主题切换：预览/面板/设置页文字与背景跟随，无白块

**本机实测现状（2026-10-21）**：第 1 步通过（WidBar 日志 `Discovered 'com.eastmg.gachacalendar' v0.1.4`，
生成了 `PluginIcons\EastMG_GachaCalendar_...png`）；第 2 步起失败：

```
[PluginProcess] 'com.eastmg.gachacalendar' faulted: Plugin process exited.
进程内 startup.log：pipe probe FAILED: UnauthorizedAccessException: Access to the path is denied.
```

同一会话里官方 Store 组件（systemmetrics / weather）为 `-> Running`，说明不是 WidBar 坏了，
而是**松散注册（-Register）的开发包连不上宿主管道**。下一步用签名安装验证（见 D）。
